# Justin Stachurski's Capstone Project

## About

This is a web game made in Typescript, using Phaser and socket.io.

## How To Run

1. Install Node.js from [here](https://nodejs.org/en/download).

2. Clone this repository.

3. In the server directory, run `npm install` to install all dependencies.

4. In the client directory, run `npm install` to install all dependencies.

5. In the server directory, run `npm run dev` to start the server.

6. In the client directory, run `npm run dev` to run the client. Open the localhost link printed in the console to play the game.

## How To Play

- Use W,A,S,D to move your character.
- Click to shoot towards your mouse cursor.
- Get points by defeating other players. Whoever has the most points when the time runs out wins.
